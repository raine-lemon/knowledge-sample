# 직무기술서 — 백엔드 개발자 (선임)

문서번호: JD-ENG-002 · 소속: 플랫폼개발본부 · 직급: L2 · 작성 2026-02-01

※ 본 문서는 지식관리 파이프라인 검증용 가상 샘플이다. 실존 기업·인물과 무관하다.

## 직무 요약

사내 핵심 서비스의 API 서버와 데이터 파이프라인을 설계·구현·운영한다. 주니어 개발자 1~2인의 코드리뷰와 기술 멘토링을 겸한다.

## 주요 업무

- REST/GraphQL API 설계 및 구현
- 데이터베이스 스키마 설계와 마이그레이션 관리
- 서비스 장애 대응 및 온콜 로테이션 참여
- 주니어 개발자 코드리뷰 및 기술 멘토링
- 분기 단위 기술 부채 정리 계획 수립

## 자격 요건

- 백엔드 개발 경력 3년 이상
- Node.js 또는 Python 기반 서버 개발 경험
- 관계형 데이터베이스 설계 및 쿼리 최적화 경험
- CI/CD 파이프라인 운영 경험

## 우대 사항

- 대규모 트래픽 서비스 운영 경험
- 클라우드 인프라(AWS/GCP) 운영 경험
