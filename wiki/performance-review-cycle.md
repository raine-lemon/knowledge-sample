# Performance Review Cycle

## Summary

반기 성과평가 사이클은 대상기간 개시 시점의 목표 확정부터 급여 반영까지를 고정된 순서로 묶은 운영 틀이다. 「인사평가 운영지침」(HR-REG-001) 제4조에 따라 평가는 반기 단위로 연 2회 실시하며, 대상기간은 상반기 1월 1일~6월 30일, 하반기 7월 1일~12월 31일이다. 실시 시기는 대상기간 종료 후 4주 이내로 2024년 제정판의 6주에서 단축됐고, 배점은 성과평가 70점·역량평가 30점이다.

## Principles

**채점 기준은 대상기간이 시작될 때 고정된다.** 성과 70점은 대상기간 개시 시점에 확정된 OKR 달성도로 산정하고(제5조 제3항), 도중에 목표가 바뀌어도 변경 전 목표로 채점하며 변경 시점과 사유만 기록한다(제4항). 역량 30점은 핵심역량 5개 항목의 행동지표로 산정한다(제5항). 기한 내 OKR을 확정한 조직은 2025년 하반기 18개 중 12개(66.7%), 2026년 상반기 19개 중 14개(73.7%)로, 첫 단계부터 온전히 지켜지지는 않고 있다.

**평가 대상은 반기말 재직 인원에서 수습 중인 인원을 뺀 수다.** 2026년 상반기는 212명에서 16명을 뺀 196명, 2025년 하반기는 198명에서 14명을 뺀 184명이었다. 채점 기준이 다르기 때문에 빼는 것이다 — 수습평가는 등급 분포를 적용하지 않고 30-60-90일 목표 달성 여부로 판단하는 별도 트랙이어서(제10조), 정규 차수에 섞으면 분포 계산이 왜곡된다. 실근무기간 60일 미만 휴직자를 "평가제외"로 처리하는 것(제3조 제4항)도 같은 분리다.

**순서를 건너뛴 결과는 확정된 결과가 아니다.** 보정회의를 거치지 않은 결과는 확정된 것으로 보지 않으므로(제11조 제4항), 아래 타임라인은 일정 권고가 아니라 효력 요건에 가깝다.

## Workflow

인사팀 업무 매뉴얼(HR-SOP-001)은 각 단계의 기한을 대상기간 종료일 기준의 상대 시점으로 못 박아 두었다.

| 시점 | 작업 | 근거 |
| --- | --- | --- |
| 대상기간 개시일 | OKR 확정 마감 공지 | 제5조 제3항 |
| 종료 + 1주 | 자기평가 오픈 | 제9조 제2항(2024) / 관행 |
| 종료 + 3주 | 1차 평가 마감 | 제9조 제3항 |
| 종료 + 4주 | 2차 평가 마감 | 제9조 제4항 |
| 2차 마감 + 1주 | 보정회의 개최 | 제11조 |
| 보정회의 + 3일 | 결과 확정·통보 (등급 근거 포함) | 제12조 제1항 |
| 통보일 + 7일 | 이의신청 접수 마감 | 제12조 제2항 |
| 접수 마감 + 14일 | 심의 완료·통보 | 제12조 제3항 |
| 결과 확정 익월 | 인상·상여 반영 급여 지급 | 급여규정 제7조·제9조 |

앞 네 단계는 자기평가에서 직속 상급자인 1차 평가자, 그 위의 2차 평가자로 올라가는 상향 순서다(제8조). 2차 평가까지의 등급은 초안이며 [[calibration-meeting]]을 통과해야 확정되고, 통보일이 [[evaluation-appeal-process]]의 7일 시계를 여는 기점이 된다. 다만 자기평가·1차·2차의 기한은 2024년 제정판 제9조에 근거하는데 개정판에는 그 조문이 없어, SOP도 "관행상 유지"라고만 적는다.

## When To Use

한 차수를 운영하거나 특정 단계의 기한을 확인할 때 기준으로 삼는다. 세부는 [[calibration-meeting]], [[evaluation-appeal-process]], [[probation-evaluation]], [[okr-performance-linkage]]로 넘긴다.
